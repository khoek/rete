# rete

A repository housing Rust web and authentication libraries.

- `arche-web`: HTTP serving, forwarding, and errors
- `arche-firestore`: Firestore connections and document helpers
- `phylax-core`: OAuth, JWT, PKCE, and refresh-token primitives
- `phylax-gcp`: Firestore authentication and identity stores
- `phylax-oidc`: OpenID Connect provider integration
